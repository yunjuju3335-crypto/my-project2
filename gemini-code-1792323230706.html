배포 사이트(GitHub Pages) 즉시 반영 센터

수정하거나 변경한 내용이 배포된 주소에 즉각 반영되도록 설정하고 점검합니다.

🔗 배포 사이트 열기 ↗
1. Supabase 클라우드 실시간 자동 동기화
권장 / 실시간

관리자가 [전체 가격 저장] 또는 사진/쇼츠를 변경하면 Supabase 클라우드에 즉시 저장되며, 배포 사이트에 접속하는 모든 손님들의 브라우저에 0.1초 만에 실시간으로 자동 렌더링됩니다.

⚠️ Supabase RLS(행 보안) 1초 해제 안내

Supabase 대시보드(supabase.com)의 SQL Editor에 아래 1줄을 붙여넣고 [Run]을 누르시면 클라우드 실시간 저장이 완전히 허용됩니다:

ALTER TABLE products DISABLE ROW LEVEL SECURITY; ALTER TABLE inquiries DISABLE ROW LEVEL SECURITY;
💻
2. PC 바탕화면 '배포하기_클릭.bat' 원클릭 푸시
영구 소스코드 배포

PC 바탕화면의 [배포하기_클릭.bat] 파일을 더블 클릭하시면, 지금까지 변경된 상품 가격, 대표 사진, 쇼츠 영상 설정이 GitHub Pages 소스 코드 자체에 자동으로 커밋 및 푸시되어 영구 배포됩니다.

🔑
3. 브라우저에서 GitHub Pages 직접 자동 배포

GitHub 개인 액세스 토큰(Personal Access Token)을 아래에 1회 등록해두시면, 관리자 창에서 [지금 GitHub Pages로 배포하기] 버튼 클릭 한 번으로 GitHub Pages가 자동 빌드됩니다.
