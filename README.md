# Baekjae Funeral Service & Goods (백제상조 웹사이트)

프리미엄 상복, 정통 수의, 장례 의전 전문 쇼핑몰 및 안내 웹사이트입니다.

## ✨ 주요 기능

1. **홈 화면 (2분할 레이아웃)**:
   - 좌측: 브랜드 슬로건 및 공식 모델 화보
   - 우측: 9:16 비율 세로형 쇼츠(Shorts) 플레이어 (로컬 영상 업로드 및 YouTube Shorts 링크 지원)
2. **핵심 가치 카드 섹션**:
   - '품격 있는 최고급 품질', '24시간 신속 배송', '정성을 다하는 전문 상담'
   - 마우스 오버 및 터치 시 탄력적인 3D 팝업(Pop-forward) 물리 애니메이션 적용
3. **상품 소개 (드래그 앤 드롭)**:
   - 각 상품 카드에 이미지를 드래그 앤 드롭하여 간편하게 변경
   - 카드 섹션의 4/3(세로 비율) 피팅 및 자동 이미지 리사이징 최적화
4. **브라우저 영구 저장 (Persistence)**:
   - 업로드한 쇼츠 영상/링크 및 드래그한 상품 이미지를 IndexedDB + LocalStorage를 통해 브라우저 새로고침 및 재접속 후에도 영구 유지
5. **다채로운 탭 내비게이션**:
   - 홈(Home), 상품소개(Products), 문의(Inquiry), 자주 묻는 질문(FAQ) 간 자연스러운 탭 전환

## 🚀 실행 방법

- **브라우저에서 바로 보기**: `index.html` 파일을 더블 클릭하거나 웹 브라우저로 엽니다.
- **React/Next.js 프로젝트 적용**: `code_artifact.tsx` 파일을 컴포넌트로 임포트하여 사용합니다.
